# Woordenlijst voor woordvalidatie

Plaats hier een Nederlandse woordenlijst als `nl.txt` met **één woord per regel**
(hoofdletters of kleine letters — beide werkt). De app laadt deze automatisch en
markeert dan gevormde woorden als *geldig* of *onbekend*.

Voorbeeld `nl.txt`:

```
aap
noot
mies
scrabble
```

Zonder woordenlijst worden woorden niet gevalideerd (er verschijnt dan geen
"geldig/onbekend"-label). De scoreberekening werkt hoe dan ook.

> Tip: officiële Scrabble-woordenlijsten zijn auteursrechtelijk beschermd. Gebruik
> een lijst die je mag verspreiden, of laat validatie uit.
